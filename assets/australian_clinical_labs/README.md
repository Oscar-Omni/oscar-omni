# au-lga.geojson

Australian local government areas for Omni custom region maps. Region property `lga`, for example `Whyalla (SA)`, unique across states. Also carries `name`, `lga_name` and `state`.

Built 7 Nov 2026 from the AUG26 Geoscape Administrative Boundaries LGA shapefiles (GDA2020) on data.gov.au, one package per state, simplified to about 120 m and rounded to 4 decimal places. ACT has no councils, so it is a single territory shape from Natural Earth admin 1.
